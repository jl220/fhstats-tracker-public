# Security

Please do not publish credentials, session cookies, private databases or an exploit that affects other players in a public issue.

Use the contact route linked from [FHStats](https://fhstats.com) to request a private reporting channel. Include the affected version and a concise description, without sending live credentials. Public issues are suitable for ordinary bugs that do not expose sensitive information.

The public desktop is a client application. It is not an official Forza component or a guarantee against cheating. Read [data and privacy](docs/privacy.md) for current defaults, capture paths and limitations.
