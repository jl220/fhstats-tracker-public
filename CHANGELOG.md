# Changelog

## 1.0.3 public source

| Change | Result |
| :--- | :--- |
| Community capture | Four registered blueprints, native game identity and clean improvements per car and class. |
| Sprint and Cross Country | Complete clean run timing alongside circuit lap timing. |
| Event restarts | Reset handling preserves clean bests and discards aborted attempts. |
| Community submissions | Persistent queue, HTTPS game submissions and receipts. |
| Home | Community track selector and timing, with expandable Online and Rivals views. |
| Garage retirement | No garage navigation or automatic scanning. Existing user files are preserved. |
| PC transport | Optional 1.0.2 UDP forwarding retired. PC submits processed community improvements. Xbox uses its own direct Data Out service. |
| Public source boundary | Private automation implementations, controls, translations and assets excluded. Independent public Git history retained. |
| Documentation | Current features, capture paths, privacy defaults, installation and limitations documented. |

This entry describes the source publication. It does not announce a rebuilt portable binary. Historical in-app release notes can mention earlier features that have since been retired.
